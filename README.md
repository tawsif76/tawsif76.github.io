# Tawsif · Research & Engineering

Published portfolio: **https://tawsif76.github.io/**

This repository contains the generated HTML, CSS, JavaScript, fonts, and media used by the public website. The original Next.js project and its source history are maintained separately in a private repository.

GitHub Actions deploys the checked-in site files to GitHub Pages when `main` changes. These are generated files; make content/design changes in the private source project, rebuild, and publish a new export here. This repository has no dependency installation or server requirement.
